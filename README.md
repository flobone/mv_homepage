# Musikverein Müsen 1919 e.V. – Website

Modernes Starter-Projekt für den Relaunch der Website des Musikverein Müsen 1919 e.V.
auf Basis von Next.js, TypeScript und Tailwind CSS.

## Enthaltene Seiten

- Home
- Aktuelles
- Termine
- Verein
- Jugendarbeit
- Galerie
- Kontakt
- Impressum
- Datenschutz

## Lokal starten

```bash
npm install
npm run dev
```

Danach im Browser öffnen:

```text
http://localhost:3000
```

## Deployment mit Vercel

1. Repository zu GitHub pushen
2. Projekt in Vercel importieren
3. Automatisch deployen lassen

## Nächste sinnvolle Schritte

- echtes Vereinslogo einbauen
- echte Fotos ergänzen
- Ansprechpartner und Kontaktdaten vervollständigen
- Impressum und Datenschutz finalisieren
- Termine aus einer Datenquelle oder einem Kalender laden
